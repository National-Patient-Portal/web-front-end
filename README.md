# National Patinet Portal
## Features
1. The software provides precise and easily comprehensible prescriptions.
2. Software generated & verified testing report.
3. Multiple medical databases creating system using centralized server.
4. The likelihood of duplicate information is reduced.
5. It features an exceptionally fast and streamlined process for account creation.
6. General user can download prescription and reports anytime anywhere using internet.
7. Medical tasks are managed with greater efficiency and effectiveness through the system’s advanced functionalities.
